# Katona Hair Restoration at Essence MedSpa

Static website for Dr. Arthur Katona's hair restoration practice at Essence MedSpa in Edgebrook, Chicago.

## Stack

- Static HTML5, CSS3, vanilla JavaScript
- Google Fonts (Cormorant Garamond, Inter, JetBrains Mono)
- Dark/light theme with localStorage persistence

## Deployment

Hosted on [Netlify](https://www.netlify.com/). Auto-deploys from `main` branch.

- **Publish directory:** `site/`
- **No build step required** — pure static files

## Structure

```
site/
├── index.html              # Homepage
├── dr-katona.html          # About Dr. Katona
├── hair-transplant.html    # FUE/FUT transplant services
├── hair-restoration.html   # Non-surgical restoration
├── advanced-aesthetics.html # Advanced aesthetic services
├── book.html               # Booking page
├── blog/                   # Blog articles
├── tools/                  # Interactive tools (cost calculator, assessment, comparison)
├── css/styles.css          # Global styles
└── js/main.js              # Theme toggle, scroll reveal, parallax
```
